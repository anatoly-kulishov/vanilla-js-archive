# Fundamentals

Core computer science building blocks for interview preparation.

## Sections

| Folder | Contents |
|--------|----------|
| [algorithms](./algorithms/) | Sorts, search, recursion |
| [data-structures](./data-structures/) | Stack, Queue, LinkedList, HashTable, Graph, BinaryTree |
| [design-patterns](./design-patterns/) | GoF patterns with Russian comments |

Most files are runnable scripts:

```bash
node fundamentals/algorithms/sorts/quickSort.js
node fundamentals/design-patterns/creational/singleton/singleton.js
```

These sections are reference implementations. Interview-specific variants may also appear under `interviews/` or `leetcode/`.
