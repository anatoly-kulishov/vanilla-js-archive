# LeetCode

Solutions grouped by difficulty and topic. Files with automated checks import `#shared/testCase`.

## Layout

```
leetcode/
├── easy/
│   ├── array/
│   ├── string/
│   ├── number/
│   ├── linkedList/
│   └── dynamic/
└── medium/
    ├── array/
    ├── matrix/
    ├── number/
    └── uncategorized/   # Custom or not yet classified
```

## Commands

```bash
node leetcode/easy/array/twoSum.js
npm run test:leetcode
```

Canonical versions of repeated tasks live in [../problems/README.md](../problems/README.md).
