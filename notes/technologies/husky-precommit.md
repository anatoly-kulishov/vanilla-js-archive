Husky pre-commit

1. Установить сам хаски

npm install --save-dev husky

2. Проинициализировать

npx husky init

3. Добавление своих команд

Команда 2 создаст папку .husky в корне и в ней в фаил pre-commit добавляем свои команды (без разделителей каждую с новой строки)(в данном случае проверка на eslint и ts)

npm run lint

npx tsc

PS: настройки можно было бы попробовать вместить в фаил packaje.json как в УБРиРе, но у меня почему то не получалось.  Так же можно было б использовать для простоты записи команд пакет lint-staged,  но в данном случае с настройками хаски в отдельной папке смотрится даже лучше.
